# Feed and desktop web

## How the feed works

- **Scrolling.** The feed uses native `UIScrollView` paging (`pagingEnabled`), so drag, flick physics, rubber-banding and one-clip-per-swipe are Apple's own. The app only reacts once a swipe settles.
- **Playback.** Three `expo-video` players cover the active clip and one neighbour on each side. Players are recycled as you swipe, so the next clip is already buffered and memory stays flat. A view attaches a player only once that player has loaded its clip, so a recycled player never flashes the previous clip.
  - Leaving the tab or backgrounding the app pauses playback.
  - Clips you leave rewind to the start.
- **Gestures.**
  - Tap pauses immediately.
  - Double-tap opens the double take on a clip with tells; on other clips it likes, with a heart burst and haptic (Dev settings choose which gesture reveals).
  - Press and hold opens the double take on a clip with tells, or plays at 2x until released.
  - Action buttons have spring feedback.
- **Sound** is on by default and plays even with the ringer switch on silent. A mute toggle sits top-left. On web, clips start muted because browsers block autoplay with sound.
- **iPhone** is locked to portrait with full-bleed video. **iPad** rotates and shows a centred 9:16 card with the action rail beside it.

## Desktop web

`npm run web` serves the same app in a browser, behind a landing page ([landing.md](landing.md)).
Windows at least 760×480 get a desktop layout (`src/desktop/`); narrower windows get the phone layout.

- **Layout.** A left icon rail, a 9:16 card filling the window height with the author on its left and the actions on its right, previous/next buttons and a Messages pill. Below 1180 px wide, the author moves inside the card.
- **Scrolling.** CSS scroll-snap plus a wheel listener that moves exactly one clip per flick, whether from a trackpad (momentum) or a mouse wheel (`wheelGesture.ts`, tested). The arrow keys, Page Up/Down and J/K also page.
- **Playback.** Three `<video>` elements are recycled over the slides, so neighbours are preloaded. Clips start muted (browser autoplay rules); M toggles sound and Space pauses.
- **Shared with the app.** The clips, social store, toasts, profile and AI tells walkthrough are the app's own. The walkthrough runs over a `<video>` through a small adapter (`HtmlVideoPlayer.ts`). Comments and Send to open as the app's sheets for now (Escape closes them).

## Source map

| Path | What it is |
| --- | --- |
| `src/app/` | Expo Router routes: `_layout.tsx` (audio session, orientation), `index.tsx` (tab shell), `/play`, `/skills`, settings |
| `src/feed/Feed.tsx` | Paged feed, three-player video pool, playback state, progress |
| `src/feed/ClipItem.tsx` | One clip: video, tap/double-tap/long-press, overlay, action rail, iPhone and iPad layouts |
| `src/feed/pool.ts` | Pure logic (pool window, page index, layout choice), tested in `pool.test.ts` |
| `src/feed/TellOverlay.tsx` | The double take walkthrough: step cards, spotlighted boxes, before/after, "also claimed" |
| `src/annotations/` | Tells format, validation, geometry, timing and walkthrough logic shared by the app and the pipeline (pure, tested) |
| `src/upload/`, `src/investigation/` | The Upload/check card, How we checked, and the job runner client |
| `src/game/`, `src/skills/` | The game round and the skills model and tab |
| `scripts/annotate/` | Pipeline that drafts tells with NVIDIA Nemotron and publishes them to the feed |
| `src/data/` | Placeholder clips, the remote feed client, stand-in comments and friends |
| `src/social/` | Engagement store (likes, saves, reposts, sends, follows, comments), actions with toasts, saving to Supabase (`sync.ts`), app navigation |
| `src/auth/` | Supabase client, auth store, the auth gate and the sign-in sheet |
| `supabase/migrations/` | Database schema and row level security |
| `src/comments/`, `src/share/` | Comments and Send to bottom sheets |
| `src/profile/` | You tab: Reposts, Shared, Liked and Saved grids |
| `src/desktop/` | Desktop web layout: icon rail, Reels-style feed with wheel and keyboard paging (web only) |
| `src/landing/` | Web landing page: clip gallery, the features tour, the launch into the feed, and the development-only design switcher |
| `src/ui/` | Pill tab bar, bottom sheet, toast, avatar and placeholder tabs |
| `assets/media/` | Original placeholder clips and posters, generated by `scripts/generate-media.sh` |
